# 60×20 布局实验

分支：`codex/layout-60x20`，起点 `5a463dc`。本轮完成构建和基本验证；内容完整性由用户目视检查，尚未通过视觉验收。

```powershell
./tools/build.ps1 -BuildDir build/layout60 -SDL
./build/layout60/credits_sdl.exe --audio ./credits.wav
```

窗口标题有 `60x20`，可与旧程序区分。按 1–6 跳转场景，P 暂停，U 切换大小写，底部颜色条继续可用。

## 排版规则

- 输出仍为 256×128。60×20 格；每格 3×5 字形，横纵各 1 像素间距，4×6 步进；原点 (8,4)。有效字形外接矩形 239×119，包含末端留白的布局区 240×120。
- 新的可移植 `layout60` 层从原始字符画布按场景分区重排，再调用核心字体光栅化。原始 80×24 模型、终端输出、随机序列和音频节拍保持原状。
- 文字按词换行；超长单词拆行；原换行保留。放不下的区域显示最后若干行，较早行向上滚出。原有缩进超过 2 格时缩为 2 格，长水平分隔线按区域宽度重画。
- 海洋：60×8，位于第 12–19 行，保留源图形两端取样。正文位于上方 12 行。
- 标题：顶部说明、中央节拍块、右下天气面板分别定位。
- 历史/天气：左侧 31 列历史，右下 28×7 天气面板，底部 2 行命令区；天气文字不缩放。
- 访问点：原有 24 项网格本身可放入 60 列，直接保留其 60×20 区域。
- 双路文字、结尾文字分成上下区域；加载框居中，正文单独换行；噪声、关机条按图形映射。

## 目视检查重点

这不是全帧缩小，也不是保证所有内容同时可见的等价版。请重点查看历史区滚动、天气与正文是否冲突、长句换行、双路文字和结尾字幕。三个种子完整回放中单帧最多滚出 6 行；这些旧行不在当前窗口中显示。图形取样会改变海洋/噪声细节。原本已经在 80×24 画布之外的内容不会凭此重排恢复。

## 实际验证

- Windows Clang-MinGW / CMake / Ninja，独立 `build/layout60` 构建通过。
- 23 项 Release 检查全部已通过：首轮 22 项通过，原有音频脚本在恢复后一轮仍检查暂停时钟的竞态被修复后，音频及布局检查重跑通过。
- 三个种子 0/1/2，共 19527 帧布局和光栅化；检查长词换行、海洋右下边界、天气面板右下字符、末格像素、留白和间距。原始 Python 对照仍通过，但不用于宣称新布局视觉等价。
- ASan/UBSan 的新布局、原字体回归、SDL 音频/交互三项通过。真实窗口运行 2 秒，864×480 RGB 回读匹配；该短测使用 dummy 音频，未重新做本分支整曲声画目视验收。
- Layout60 由播放器持有，4804 字节；无新增堆分配。framebuffer 仍为 4096 字节。编译器单函数静态栈 layout60_render 88 字节、render_grid 120 字节，不代表整条调用链栈高水位。
