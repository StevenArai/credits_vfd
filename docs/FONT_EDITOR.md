# 本地 3×5 字形编辑器

双击 `tools/font-editor.html`，用 Edge 或 Chrome 打开即可；单文件离线工作，不需要服务器或第三方脚本。

- 左侧选择字形，右侧点击或按住拖动 15 个像素；支持撤销、重做、清空、反色、恢复当前字形。
- 输入 `°` 或 `U+00B0` 添加缺字；目前仅支持与 C 画布一致的 BMP 字符，NBSP 固定为空格。
- 下方预览 60×20 布局，可选择大写转换和发光色；显示缺字和超出窗口的字符数量。
- **复制当前字形**：适合改一两个字，直接把文本粘贴给助手。包含字符、Unicode、15 位点阵及五行可读点阵。
- **导出整套字体**：下载 JSON，适合备份和批量修改；**导入文件 / 粘贴字形** 可加载整套或合并单字。
- 浏览器不允许自动写剪贴板时，会弹出已选中的文本供手动复制。

自动保存只在当前浏览器的本地存储中；换浏览器、清理缓存或改变文件位置可能无法恢复。请以导出 JSON 为正式备份。导出本身不会修改项目或重编译。

在项目根目录应用文件：

```powershell
python tools/export_font.py --input "D:/你的字体文件.json"
./tools/build.ps1 -BuildDir build/font-preview -SDL
./build/font-preview/credits_sdl.exe --audio ./credits.wav
```

导入器更新 `tools/font-editor-data.json`、编辑器内嵌默认字体和两个 C 字形表；95 个 ASCII 必须齐全。部分字形合并，含完整 ASCII 的文件整体替换。附加字形进入 `font_extra_generated.inc`，不再显示问号。原始 `archive/fonts/3x5fonts.html` 保留不变。浏览器已存的编辑草稿仍优先，可通过导入新文件或“恢复原字”选取新的默认值。

已实际验证：Node 下的编辑/撤销/重做/添加/复制/导入/缓存/非法数据检查（DOM 替身）；临时目录单字 JSON 导入、保留 ASCII、导出一致性、实际编译并渲染新增度数字形；C 字体像素和布局回归。测试用度数字形没有写入项目，仍待用户设计。
