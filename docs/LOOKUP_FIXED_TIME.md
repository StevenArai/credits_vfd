# 数值查表与定点播放器 — 2026-10-06

## Q32.32时间精度

`FixedTime`为64位有符号Q32.32秒：1 LSB = 2^-32秒，约0.232831纳秒；非负时钟可表示约68年。帧计数另受int范围约束。

- 采样/计数器转换：`fixed_time_ratio(count, frequency)`将有理秒数直接转定点，向下误差严格小于1 LSB；没有先经过double。检查零频率和可表示范围。
- 节拍周期为精确的15/358秒。截止时间统一写成 `(1373*179 + (beat-1)*1875)/44750` 秒，包含5.492秒偏移。
- 初始化计算整数部分及余数，随后逐拍只加定点商、累积余数并进位。每个截止时间是理想有理值向下取整，误差小于1 LSB，**不随拍数累积**。
- 使用严格 `position > next_beat`。外部真实媒体时间转换后，临界点可能延迟不到1 LSB，不承诺复现旧double在亚纳秒边界的二进制舍入。
- 30Hz输入采样阈值在定点域比较；连同两端时钟量化，边界误差小于2 LSB。快进在直接step模式保存分数余数；sync模式每次以真实媒体位置为准重新锚定。
- SDL的诊断、颜色条、音频seek适配仍可使用double，不属于定点播放器运算。声卡/队列/调度精度仍受实际采样周期和硬件限制，Q分辨率不代表物理同步精度。

EOF依据已消费字节数判断，而不是向下量化后的时间与double总时长比较。否则非整数秒WAV可能永远略短于总时长，无法退出。

## 实测资源与剩余热点

- 链接阶段计数：pow2883→0，cos954→0，sin3864→1002，floor942→1。剩余sin来自天气，floor仅初始化一次。原生静态库不再引用pow/cos。
- 实际player_fixed.c以Cortex-M0 soft ABI编译，汇编无浮点辅助调用；初始化/比率转换/快进仍有64位整数除法。没有目标libc链接或板端周期验证，不宣称M0已达到实时要求。
- Credits10776B、framebuffer4096B、主机堆峰值25184B和39次分配均不变。FixedPlayer为72B（host/ARM ABI），旧Player56B，增加16B，独立于Credits。
- 既有ARM主要对象投影34476B原先未包含播放器；加入当前72B播放器为34548B（约33.74KiB），仍不含栈、分配器、驱动及少量静态状态。表属于只读/XIP，不计入该RAM投影。
- 非插桩主机动画全程10.68–12.94ms、像素136.16–154.40ms。1000Hz定点轮询五次中位13.4706ms，未证明主机显著提速；收益是去除目标软浮点路径，不用Windows耗时推算M0周期。
- 天气仍保留double模拟和浮点格式化，尚未定点化；本轮查表已无差异解决所选pow/海面问题，不需要用近似定点模拟替代。
