# 原生单精度与天气正弦近似

2026-10-06，用户要求尝试将MCU核心double改成float，并提供了10度正弦/1度余弦小表近似式。当前原生运行版已采用单精度与改进后的小表算法。终端参考仍使用原double版本，Q32.32播放器保持不变。

## 当前实现

- `weather60.c` 为原生单精度天气，`weather.c` 为原始终端对照。Weather字段及计算使用float，所有非整数常量带f后缀，原生场景的天气概率参数也为float。
- 百分比先用float转换到百分之一百分点，按最近偶数舍入，再以整数格式输出；不再将float通过可变参数提升为double，也不要求浮点printf路径。显示规则明确以量化后的单精度值为准，不承诺旧double边界舍入逐字相同。
- 原生初始海洋相位改为 `random_scaled(...,2000)`，用整数重现原53位random值乘法的最近偶数舍入及floor，保留两次MT抽取。参考构建仍保留double random_unit。
- 原生编译的单头实现没有double运算。SDL的宿主音频/诊断/颜色条适配，以及测试oracle可以继续使用double；目标libc内部实现也不在该声明范围内。

Weather字段变化会改变实例布局，替换单头库后应重新编译所有使用它的C文件。当前回归和代码生成审计禁用浮点收缩（Clang/GCC的 `-ffp-contract=off`），未使用fast-math；更换这些选项可能再次改变边界舍入和随机分支，板端复现摘要时应保持一致。

## 小表算法及误差

使用用户方案的角度归约、sin(a+b)展开和两张小表。原式 `cos_table[(int)b]` 会忽略b的小数部分；正弦小角近似b×π/180也有截断误差。初步0–90度、0.001度间隔的float32扫描中，原式最大误差约0.00300654，对应天气目标温度约0.12026°F。

当前实现：

- sin表为0–90度，每10度一项；cos表为0–10度，每1度一项（新增10度端点）。共21个float，**84 B只读数据**。
- cos(b)在相邻两项间线性插值；小角sin(b)用 `r*(1-r*r/6)`，r为弧度。全过程float，不调用libm。
- `math_sin_degrees`只接受有限的[-360,360]度，越界报错，不用无界循环归约。天气先在整数域做365天取模，再转换角度，实际输入始终在范围内。
- 720001个[-360,360]角度样本相对主机double sin的最大误差 **3.76085159e-5**；20001个整数日的天气目标温度最大误差 **0.00149934726°F**。测试覆盖象限、端点、负日期和周期，不把扫描当成对全部实数的形式证明。

## 行为变化与回归

这是一次数值精度变更。即使正弦误差很小，天气参数参与整数截断、随机上界和分类；跨过边界后，后续随机抽取可能不同，进而影响天气、随机加载进度等画面。

相对修改前的原生18-PBS版本，3种子×6起点共72132帧：

| 检查 | 结果 |
| --- | --- |
| 事件/打字节拍摘要 | 一致 |
| 主RNG状态不同 | 29099帧 |
| 字符/属性不同 | 8304帧 |
| framebuffer不同 | 8255帧，约11.4% |

不能将这次变更报告为逐帧无差异优化。原始Python和终端参考没有修改；原生时间线、海洋规则、布局与字体未因数值实验另行改动。修正前后源码身份及完整比较见 [float-weather证据](validation/2026-10-06/float-weather/README.md)。

## 资源与F401适用性

ARM Weather由56 B变为32 B，五份共省120 B；Animator由34872 B变为 **34752 B（33.94 KiB）**。主机对象由40584 B变为40504 B。工作区、char_buf及fb不变；旧离散表10821 B加本次84 B，合计10905 B。

使用Clang编译实际单头实现，目标为Cortex-M4、fpv4-sp-d16、hard-float ABI：IR中无double类型，无双精度软件辅助调用，也无sin/cos/pow/floor导入；生成单精度FPU指令。`-Wdouble-promotion`作为错误检查通过。

这是带声明式libc头的代码生成审计，不是完整F401固件。sscanf、整数snprintf、默认fprintf/abort等依赖仍存在，目标libc代码及其内部开销需实际链接检查。编译器给出的单函数栈最大408 B、天气绘制288 B，不是调用链/中断总栈。尚未测量板端周期或确认实际提速比例。

Release相关17项、ASan/UBSan相关4项、内嵌WAV版相关5项均通过；普通和单文件SDL EXE已重建。最新画面仍由用户目视确认。
