# 场景直接写 60×20 字符画布

本轮分支 codex/direct-60x20，参考基线 f043f98。优化方向先记录于 OPTIMIZATION_PLAN.md。

## 运行结构

SDL 链接 credits_core60；它不包含 canvas.c 的 Section 管理或 layout60.c 的后处理。
SDL 前端只把核心提供的字符画布交给核心光栅化函数，显示 framebuffer，并适配时间/输入/音频。
所有场景坐标、换行、滚动、覆盖、光标和字体仍在无 SDL 依赖的 C 模块中。

```
场景 / 文字 / 海洋状态
        ↓ 直接写入
Canvas.cells[1200]   60×20，uint32_t 字符 + 属性 + 光标标志
        ↓ framebuffer_render60
Framebuffer.bits[4096]   256×128，1bpp
        ↓
SDL 或将来的硬件显示适配
```

SDL 的 Credits 实例与 framebuffer 均为静态存储。字符画布为实例内的唯一字符格数组，
4800 B；另有 12 B 的背景/滚动/裁剪计数。没有第二张 Layout60，也没有 80×24 中间画布。
海洋模拟仍保留原 80×10 数据和 RNG 消耗，直接选取 60×8 样本写入显示区；它是动画状态，
不是隐藏的终端画布。本轮未进行浮点或海洋字符窄化优化。

credits_core 是独立的终端参考构建，继续运行 Python 对照。共享随机、调度、事件、
初始化、海洋模拟、天气计算与文字业务状态；scenes.c / scenes60.c 分别提供参考和直接布局。
二者只在各自的静态库中编译，不在 SDL 运行实例里并存。当前两份场景回调仍有相似逻辑，
因此新增逐拍业务摘要对照，防止直接布局改变随机抽取及事件行为。

## 原生分区与有意变化

| 内容 | 直接布局 |
|---|---|
| 海洋 | 行 12–19，60×8；上方文字按词换行并在自己的区域滚动 |
| 标题与节拍块 | 用户文案直接写入；块位于 (26,7)，8×4 |
| 天气 | (32,11)，28×7；日期、天气、风速等直接写入该面板 |
| 资助历史 | 左侧 31×18，完整新行向上滚动；当前输入位于行 19 |
| 加载条 | (13,7)，34×3；进度限定在 32 格内部，文字在行 11 以下 |
| 双路文字 | 顶部文字区、行 12–18 历史区、行 19 输入，各自管理换行 |
| 接入点 | 原 24 个节点按 60 列直接放置，底部状态三行 |
| 结尾 | 文字在行 1–5，节拍块在行 7–10，底部文字在行 16–19 |

普通覆盖使用调用顺序；不再模拟 Python Section 排序和跨 80 列写入的副作用。
开场噪声坐标映射到本地 60×20，保留随机调用；原加载条越界到框外的内容不再显示。
文字在目标区域按词换行/滚动，清除自身区域；资助历史去除前后填充空格后加前缀。
结尾文字避开节拍块。标题、面板的空白格可能保留不同属性，但无可见像素差异。
这些变化属于直接布局，不能声称整曲逐像素不变；最终内容/观感由用户检查。

可写对象、分配器元数据/碎片和驱动。不是 MCU 实测或完整 RAM 上限。

| 分配归属 | 全曲次数 | x64 峰值时存活 | ARM 投影 |

总计 39 次，初始化 28 次，播放期间 11 次容量建立/增长；销毁 live=0。
没有宣称整个播放零分配。旧 seed 1 为 90,225 次，其中画布缓冲 89,723 次。
新路径不存在 Section 分配，不是简单给旧分配器加池。

当前 x64 Release 单函数静态栈最大 504 B（场景回调），海洋 update 200 B；
旧 clear 7736 B、海洋 update 3416 B 已不在直接核心路径中。这不是调用链高水位。
无输出干扰的 profile 中动画含直接布局约 2.1 µs/帧，光栅化约 20–21 µs/帧；
光栅化比旧 profile 的约 13 µs 更慢，本轮不隐瞒该结果，也不将主机均值外推 MCU。
像素生成仍远小于逻辑拍间隔；热点原因及优化属于后续测量。

## 海面轮廓修正

用户已目视接受直接布局，另指出海面 # 缺口。旧10→8点采样跳过源行4/8，
即使与旧布局逐格一致，也会丢失一格厚的海面。现在将行4/5和8/9分别合并，
保留组内实际渲染的 #；没有 # 时沿用末行字符，随机故障仍由原算法生成。
新 ocean60_contour 独立对照测试覆盖全部高度与故障档位，不再用有同样缺陷的
旧布局作为轮廓正确性的依据。整体布局已接受，此修复待用户复看。
不增加画布、堆或分配次数；验证和资源数据见 PLAN.md 海面修复记录。
