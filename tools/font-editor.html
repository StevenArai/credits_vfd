VFD 3×5 字形编辑器

十五个像素，一个字符。离线编辑，无需安装。

字形库

点击或按住拖动修改像素。复制后可直接粘贴给助手；修改少数字形不必导出整套文件。

自动保存仅保存在本浏览器。请导出 JSON 备份；这里的修改不会直接改变播放器。

60×20 布局预览

3×5 字形、4×6 步进、原点 (8,4)，发光点 2×2 像素，黑缝 1 像素。缺字以 ? 显示并提示。此处用于检查字形和间距，动画实际排版以播放器为准。

用于项目

保存导出的 JSON 后，在项目目录运行：

python tools/export_font.py --input "你的字体文件.json"
./tools/build.ps1 -BuildDir build/font-preview -SDL

也可用“复制当前字形”发给助手合并。原始 3x5fonts.html 保持不变。

导入字体或字形

整套字体替换当前内容；单字合并。导入操作可撤销。
